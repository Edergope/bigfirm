# Method Routing

| Tipo de problema | Método principal | Métodos auxiliares | Métodos no recomendados |
| ---------------- | ---------------- | ------------------ | ----------------------- |
| Problema causal no delimitado | árbol de problemas | cinco porqués, Ishikawa, observación | redacción inmediata |
| Proceso repetitivo con errores | DMAIC | Pareto, Lean, análisis de datos | Six Sigma sin datos |
| Startup o modelo nuevo | Lean Startup | Design Thinking, análisis regulatorio, premortem | MVP para evadir obligaciones |
| Problema estructural | pensamiento sistémico | árbol de problemas, actores, escenarios | causa única simplista |
| Decisión estratégica | árbol de decisión | escenarios, costo-beneficio, premortem, Red Team | decisión sin alternativas |
| Operación M&A | workstreams | stage-gate, due diligence, issue list, closing checklist | redacción sin DD |
| Insolvencia | árbol de problemas | teoría de restricciones, escenarios, flujo de caja, negociación | ocultamiento o simulación |

## Regla de liderazgo

Los métodos auxiliares no sustituyen especialistas jurídicos. El orquestador evita usar demasiados métodos simultáneamente y exige propósito, artefacto y gate.
