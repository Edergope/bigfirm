# Validación de profundidad de agentes 03C

Un agente no se considera completo si no satisface, cuando aplique: identidad diferenciada, perfil profesional, materias incluidas, materias excluidas, problemas específicos, preguntas obligatorias, metodología, secuencia de análisis, matrices, riesgos, señales de alerta, reglas de decisión, escalamiento, entregables, auditorías, bloqueos, trazabilidad, no alucinación y ejemplos abstractos.

Los agentes críticos del Micro Sprint 03C deben estar marcados como `status: active`, `version: 0.3.0`, `experience_profile: senior-specialist` y `requires_human_approval: true`.
